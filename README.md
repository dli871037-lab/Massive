# 

# \## Условие

# 

# Требуется:

# 

# 1\. Запросить количество строк и столбцов матрицы.

# 2\. Проверить, что размеры находятся в допустимом диапазоне:

# &#x20;  - от `1` до `20`.

# 3\. Ввести элементы матрицы.

# 4\. Проверить, что каждый элемент:

# &#x20;  - является целым числом;

# &#x20;  - находится в диапазоне от `-1000` до `1000`.

# 5\. Вывести исходную матрицу.

# 6\. Вычислить суммы элементов каждого столбца.

# 7\. Вывести полученные суммы.

# 

# Если ввод некорректен, программа выводит:

# 

# ```text

# INVALID

# ```

# 

# и завершает работу.

# 

# \## Формат ввода

# 

# Сначала вводятся два числа:

# 

# ```text

# rowCount columnCount

# ```

# 

# где:

# 

# \- `rowCount` — количество строк;

# \- `columnCount` — количество столбцов.

# 

# Затем вводятся элементы матрицы по строкам:

# 

# ```text

# a00 a01 a02 ...

# a10 a11 a12 ...

# ...

# ```

# 

# Общее количество элементов:

# 

# ```text

# rowCount \* columnCount

# ```

# 

# \### Пример корректного ввода

# 

# ```text

# 2 3

# 1 2 3

# 4 5 6

# ```

# 

# \## Пример работы

# 

# Ввод:

# 

# ```text

# 2 3

# 1 2 3

# 4 5 6

# ```

# 

# Примерный вывод:

# 

# ```text

# Enter the count of rows and columns in turn.

# Enter 6 elements in turn.

# Matrix P:

# 1 2 3

# 4 5 6

# Sums of columns of P

# 5 7 9

# ```

# \### 1. Как массив хранится в памяти и что означает его индекс?

# 

# Массив хранится в памяти как непрерывная последовательность элементов. Элементы располагаются друг за другом.

# 

# Индекс показывает смещение от начала массива. Например, запись:

# 

# ```cpp

# P\[i]\[j]

# ```

# 

# означает доступ к элементу, который находится в строке `i` и столбце `j`.

# 

# Для одномерного массива:

# 

# ```cpp

# a\[i]

# ```

# 

# означает элемент со смещением `i` от начала массива. Адрес элемента можно вычислить как:

# 

# ```text

# base + i \* sizeof(element)

# ```

# 

# Поэтому доступ по индексу выполняется быстро.

#

# 

# \### 2. Чем отличаются число объявленных ячеек, фактическая длина и размер в байтах?

# 

# В программе объявлен массив:

# 

# ```cpp

# int P\[maxSize]\[maxSize];

# ```

# 

# где:

# 

# ```cpp

# constexpr int maxSize = 20;

# ```

# 

# Число объявленных ячеек:

# 

# ```text

# 20 \* 20 = 400

# ```

# 

# Это максимальное количество элементов, которое можно хранить в массиве.

# 

# Фактическая длина — это количество реально используемых элементов. В данной программе оно равно:

# 

# ```text

# rowCount \* columnCount

# ```

# 

# Например, если введена матрица `2 × 3`, фактически используется:

# 

# ```text

# 2 \* 3 = 6

# ```

# 

# элементов.

# 

# Размер в байтах — это объём памяти, который занимает массив. Для `P` он равен:

# 

# ```cpp

# sizeof(P)

# ```

# 

# Обычно `int` занимает 4 байта, поэтому массив `20 × 20` занимает примерно:

# 

# ```text

# 20 \* 20 \* 4 = 1600 байт

# ```

# 

# Для массива сумм столбцов:

# 

# ```cpp

# int columnSums\[maxSize] = {};

# ```

# 

# объявлено 20 ячеек, фактически используется `columnCount`, а размер в байтах:

# 

# ```cpp

# sizeof(columnSums)

# ```

#

# \### 3. Почему доступ по готовому индексу имеет оценку O(1), а последовательный поиск – O(n)? Сколько элементов нужно просмотреть в прямоугольной матрице?

# 

# Доступ по индексу имеет сложность `O(1)`, потому что адрес элемента вычисляется сразу:

# 

# ```text

# base + index \* sizeof(element)

# ```

# 

# Для этого не нужно перебирать элементы.

# 

# Последовательный поиск имеет сложность `O(n)`, потому что в худшем случае нужно проверить все элементы.

# 

# Для прямоугольной матрицы размером `rowCount × columnCount` общее количество элементов:

# 

# ```text

# rowCount \* columnCount

# ```

# 

# Если нужно найти элемент во всей матрице, в худшем случае придётся просмотреть:

# 

# ```text

# rowCount \* columnCount

# ```

# 

# элементов.

# 

# Если нужно просмотреть одну строку:

# 

# ```text

# columnCount

# ```

# 

# Если нужно просмотреть один столбец:

# 

# ```text

# rowCount

# ```

#

# \### 4. Почему два полных прохода сохраняют оценку O(n)? Как работает сортировка выбором и почему число её сравнений растёт как O(n²)?

# 

# Если сделано два полных прохода по массиву из `n` элементов, количество операций примерно:

# 

# ```text

# n + n = 2n

# ```

# 

# В оценке сложности константы отбрасываются, поэтому:

# 

# ```text

# O(2n) = O(n)

# ```

# 

# Сортировка выбором работает так:

# 

# 1\. В неотсортированной части массива ищется минимальный элемент.

# 2\. Он меняется местами с первым элементом неотсортированной части.

# 3\. Отсортированная часть увеличивается на один элемент.

# 4\. Процесс повторяется.

# 

# Количество сравнений:

# 

# ```text

# (n - 1) + (n - 2) + (n - 3) + ... + 1

# ```

# 

# Это равно:

# 

# ```text

# n \* (n - 1) / 2

# ```

# 

# То есть растёт как:

# 

# ```text

# O(n²)

# ```

#

# \### 5. Как получить индекс по номеру из условия и проверить его допустимость?

# 

# В коде индексы начинаются с `0`. Если в условии номер начинается с `1`, нужно вычесть единицу:

# 

# ```cpp

# int index = number - 1;

# ```

# 

# Проверка допустимости:

# 

# ```cpp

# if (index < 0 || index >= n) {

# &#x20;   // номер недопустим

# }

# ```

# 

# Для матрицы:

# 

# ```cpp

# int i = rowNumber - 1;

# int j = columnNumber - 1;

# 

# if (i < 0 || i >= rowCount || j < 0 || j >= columnCount) {

# &#x20;   // номер недопустим

# }

# ```

# 

# В данной программе размеры проверяются так:

# 

# ```cpp

# rowCount < 1 || rowCount > maxSize

# columnCount < 1 || columnCount > maxSize

# ```

#

# \### 6. Как отличаются строка и столбец матрицы и в каком порядке расположены элементы в памяти?

# 

# Строка матрицы — это элементы с одинаковым номером строки:

# 

# ```text

# P\[i]\[0], P\[i]\[1], P\[i]\[2], ...

# ```

# 

# Столбец матрицы — это элементы с одинаковым номером столбца:

# 

# ```text

# P\[0]\[j], P\[1]\[j], P\[2]\[j], ...

# ```

# 

# В C++ обычные двумерные массивы хранятся по строкам:

# 

# ```text

# P\[0]\[0], P\[0]\[1], P\[0]\[2], ..., P\[1]\[0], P\[1]\[1], ...

# ```

# 

# То есть сначала идут элементы первой строки, затем второй и так далее.

# 

# Для массива:

# 

# ```cpp

# int P\[maxSize]\[maxSize];

# ```

# 

# память выделяется под `maxSize` строк по `maxSize` элементов в каждой.

#

# \### 7. Почему на главной диагонали индексы равны, а на побочной постоянна их сумма?

# 

# Для квадратной матрицы `n × n`:

# 

# Главная диагональ идёт из левого верхнего угла в правый нижний:

# 

# ```text

# P\[0]\[0], P\[1]\[1], P\[2]\[2], ...

# ```

# 

# У всех элементов главной диагонали:

# 

# ```cpp

# i == j

# ```

# 

# Побочная диагональ идёт из правого верхнего угла в левый нижний:

# 

# ```text

# P\[0]\[n - 1], P\[1]\[n - 2], P\[2]\[n - 3], ...

# ```

# 

# У всех элементов побочной диагонали сумма индексов одинакова:

# 

# ```cpp

# i + j == n - 1

# ```

# 

# \---

# 

# \### 8. Как выбрать область выше или ниже каждой диагонали?

# 

# Для квадратной матрицы `n × n`:

# 

# Главная диагональ:

# 

# ```cpp

# i == j

# ```

# 

# Выше главной диагонали:

# 

# ```cpp

# i < j

# ```

# 

# Ниже главной диагонали:

# 

# ```cpp

# i > j

# ```

# 

# Побочная диагональ:

# 

# ```cpp

# i + j == n - 1

# ```

# 

# Выше побочной диагонали обычно считают элементы:

# 

# ```cpp

# i + j < n - 1

# ```

# 

# Ниже побочной диагонали:

# 

# ```cpp

# i + j > n - 1

# ```

# 

# Например, область выше обеих диагоналей можно выбрать условием:

# 

# ```cpp

# i < j \&\& i + j < n - 1

# ```

# 

# \---

# 

# \### 9. Почему центральный элемент при сложении диагоналей иногда нужно учитывать один раз?

# 

# Если размер квадратной матрицы нечётный, например `3 × 3`, `5 × 5`, `7 × 7`, главная и побочная диагонали пересекаются в центре.

# 

# Например, для матрицы `3 × 3` элемент:

# 

# ```text

# P\[1]\[1]

# ```

# 

# принадлежит и главной, и побочной диагоналям.

# 

# Если отдельно сложить главную диагональ и отдельно побочную, центральный элемент будет учтён дважды.

# 

# Чтобы учесть его один раз, можно либо вычесть его один раз:

# 

# ```cpp

# sum = mainSum + secondarySum - P\[n / 2]\[n / 2];

# ```

# 

# либо использовать одно условие:

# 

# ```cpp

# if (i == j || i + j == n - 1) {

# &#x20;   sum += P\[i]\[j];

# }

# ```

# 

# Для чётного размера матрицы центрального элемента нет, поэтому вычитать ничего не нужно.

#

# \### 10. Какие тесты нужны для матрицы 1×1, прямоугольной матрицы и нечётной квадратной матрицы? Как проверить формат вывода?

# 

# Для проверки программы полезны следующие тесты.

# 

# \#### Матрица 1×1

# 

# Ввод:

# 

# ```text

# 1 1

# 5

# ```

# 

# Ожидаемый результат:

# 

# \- матрица выводится как `5`;

# \- сумма единственного столбца равна `5`.

# 

# \#### Прямоугольная матрица

# 

# Ввод:

# 

# ```text

# 2 3

# 1 2 3

# 4 5 6

# ```

# 

# Ожидаемый результат:

# 

# ```text

# 1 2 3

# 4 5 6

# ```

# 

# Суммы столбцов:

# 

# ```text

# 5 7 9

# ```

# 

# Этот тест проверяет, что программа корректно работает, когда количество строк и столбцов не совпадает.

# 

# \#### Нечётная квадратная матрица

# 

# Ввод:

# 

# ```text

# 3 3

# 1 2 3

# 4 5 6

# 7 8 9

# ```

# 

# Ожидаемая матрица:

# 

# ```text

# 1 2 3

# 4 5 6

# 7 8 9

# ```

# 

# Суммы столбцов:

# 

# ```text

# 12 15 18

# ```

# 

# Если бы вычислялись диагонали, этот тест проверил бы, что центральный элемент не учитывается дважды.

# 

# \#### Проверка формата вывода

# 

# Нужно проверить:

# 

# \- правильность чисел;

# \- наличие нужных заголовков;

# \- количество пробелов между числами;

# \- переводы строк;

# \- отсутствие лишних символов.

# 

# В данной программе суммы столбцов выводятся через пробел:

# 

# ```cpp

# cout << columnSums\[Index] << " ";

# ```

# 

# Если требуется строгий формат без пробела после последнего числа, вывод лучше изменить:

# 

# ```cpp

# for (int Index = 0; Index < columnCount; ++Index) {

# &#x20;   if (Index > 0) {

# &#x20;       cout << " ";

# &#x20;   }

# &#x20;   cout << columnSums\[Index];

# }

# cout << "\\n";

# ```
